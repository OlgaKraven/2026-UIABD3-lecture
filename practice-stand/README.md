# Учебный стенд MySQL: 3 курс

Windows x64, PowerShell 5.1 или новее. Распакуйте весь комплект в одну папку, откройте её в PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
.\client.ps1
```

Первый запуск скачивает официальный MySQL 8.4.13 (~270 МБ), проверяет SHA-256, создаёт локальный экземпляр 127.0.0.1:33063 и базу uiabd3_training. Не нужны Docker, установленный клиент или служба Windows. Данные и случайные пароли хранятся в %LOCALAPPDATA%\UIABD3-study, вне комплекта лекций. Пароли автоматически применяются клиентом и не печатаются. Не передавайте state.json и каталог данных другим людям.

```sql
SELECT VERSION(),CURRENT_USER(),DATABASE(),@@port;
```

Для создания отдельного учебного пользователя и наблюдения Performance Schema: `.\client.ps1 -Admin`. Файл читают в нужном сеансе командой `SOURCE sql/04-rights.sql;` или целиком из PowerShell `.\client.ps1 -Admin -File .\sql\04-rights.sql`. SQL из лекций выполняйте в указанном порядке; файлы с CREATE TABLE запускайте один раз в новой учебной базе. Они не очищают имеющиеся таблицы.

Новый пользователь входит через `.\client.ps1 -User uiabd3_reader` и пароль из CREATE USER. Для транзакционных упражнений откройте два клиента A/B и третий административный для наблюдения; команды и ожидаемые ответы приведены непосредственно в лекции.

Штатный останов: `.\stop.ps1`. Повторный `.\start.ps1` сохраняет данные. Скрипты не регистрируют и не заменяют службы Windows. Для второго независимого экземпляра задайте новую пустую папку `-Root` и свободный `-Port`; передавайте тот же Root клиенту и останову. Непустая чужая папка не инициализируется.

После отзыва всех прав базы войдите без её выбора: `.\client.ps1 -User uiabd3_reader -NoDatabase`, затем выполните `SELECT * FROM uiabd3_training.access_stock;`. Так проверяется запрет операции 1142; обычный вход с выбором недоступной базы может завершиться раньше с 1044.
