# Локальный runtime лекционного сайта

Рабочий runtime находится в `runtime/` и подключён как локальная зависимость. Его основа — архив `vendor/olgakraven-lecture-engine-0.1.1-okfks.10-visuals.2.tgz`. Скрипт `scripts/prepare-runtime.py` разворачивает закреплённый архив и применяет оформление панели, модальные схемы и совместимость заметок; результат хранится в Git. Исходный общий шаблон при этом не изменяется.

Архив `vendor/olgakraven-lecture-engine-0.2.1-uiabd.1.tgz` используется для содержательной валидации. `integration.patch` сохраняет происхождение расширения этого пакета; версия рабочего runtime — `0.1.1-uiabd3.1`. Учебное содержание и модели 3 курса находятся в `authoring/` и `src/learning/` данного репозитория.
