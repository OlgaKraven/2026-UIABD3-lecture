# Содержание и проверка

Исходный состав тем сохранён в `authoring/source-baseline.json`. Тексты и предметные примеры находятся в `authoring/lectures/`, дополнительные вопросы — в `authoring/checkpoints.mjs`, выполняемая практика — в `authoring/practice.mjs` и `public/practice/`. Реестр технических источников — `SOURCES.md`.

Сборка создаёт слайды, отдельный сценарий преподавателя, ключи самопроверки и карту старых числовых ссылок. Проверка не подменяет содержательный аудит: отчёты с результатами исполнения SQL и браузерного прохода хранятся отдельно в `reports/`.
