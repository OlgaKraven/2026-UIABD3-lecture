# Источники и воспроизводимость

- Человекочитаемый реестр: `../../SOURCES.md`.
- Машиночитаемый реестр: `../../src/data/sourceRegistry.ts`.
- Утверждённые формулировки тем: локальный тематический план; публичная копия не создаётся.
- Условные числовые значения на экранах обозначаются как исходные данные учебной задачи.
- Команды сверяются с документацией MySQL 8.4; синтаксис PostgreSQL используется только в сравнительной теме.
- `sourceIds` добавляются к каждому экрану с проверяемым техническим, библиографическим или нормативным утверждением.
